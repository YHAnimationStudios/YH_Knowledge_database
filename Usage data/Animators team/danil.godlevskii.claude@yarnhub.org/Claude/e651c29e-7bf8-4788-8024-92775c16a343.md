    ## Cost of one plane
    
    All nine `BP_B25_Mitchell_Crew_*` blueprints are built the same way. Per plane:
    
    | Part | Type | Triangles | How ray tracing handles it |
    |---|---|---|---|
    | `SK_B25_Mitchell` (hull) | Skeletal, Anim BP + Control Rig | **1,392,183** | Each plane gets its own copy, updated every frame |
    | `SK_B25_Mitchell_Cockpit` | Skeletal, Anim BP | **761,031** | Same |
    | `SK_MarkTwainBombsight` | Skeletal | 3,332 | Same |
    | 4× `SM_AN-M54_500lb` bombs | Static | 4 × **205,548** | Shared between planes |
    | Navigator's compartment | Static | 157,749 | Shared |
    | Wheels, props, benches, tanks | Static | ~160k | Shared |
    | **Total** | | **~3.3M** | |
    
    Across 16 planes that's about **53M triangles**. About **34.5M** of those are skinned, so none of it is shared between planes and all of it is updated every frame.
    
    - **No optimisation on any mesh:** every mesh has 1 LOD, Nanite is off and Ray Tracing Min LOD is 0. A ray-tracing LOD bias would do nothing today, because there's no lower LOD to drop to.
    - **Everything always animates:** all three skeletal components are set to `AlwaysTickPoseAndRefreshBones` and have no ray tracing group ID.
    - **Hidden interiors still count:** the cockpit, navigator's compartment, bombs and bombsight are invisible from outside but are still part of the ray-traced scene.
    - **Hull by material:** about 300k triangles (22%) are clearly interior (bomb bay 150k, interior details 112k, B-17/Lancaster props ~38k). The turret is 130k. `Metal_Gray` is 553k (40%), and the data can't tell whether that's internal structure or exterior detail. So removing the interior isn't enough on its own; the hull also needs real decimation (polygon reduction).
    
    ## What I'd build: a "Background" mode inside the existing blueprints
    
    These planes are animated through the Anim BP, Control Rig and Sequencer. Replacing them with a new blueprint class would break the bindings in every shot, so the optimisation should live inside the existing blueprints.
    
    1. **Add a reduced LOD1 to the hull mesh** (`SK_B25_Mitchell` and its DMG variants). Turn off the interior sections in LOD1 and reduce it to roughly 150–200k triangles. It keeps the same skeleton, so gear, flaps, bomb bay doors, turret and Control Rig keep working.
    2. **Add a Hero/Background switch to the blueprints.** In Background mode:
       - The hull is forced to LOD1.
       - The cockpit, bombsight, navigator's compartment, benches, tanks and bombs are hidden.
       - Animation only ticks when the plane is on screen (`OnlyTickPoseWhenRendered`).
       - Each plane gets its own ray tracing group ID.
    
       Animators tick a box per plane and nothing needs rebinding. My estimate for 15 background planes plus 1 hero is about 5M skinned triangles instead of 34.5M, roughly 85% less.
    3. **Fix the heavy static meshes.** 205k triangles for one bomb is an asset problem. UE 5.8's per-mesh Ray Tracing Proxy setting is off on every one of these meshes. Turning it on, or enabling Nanite, would help for the bomb, the navigator's compartment and the wheels.
    
    **Optional extra tier:** for planes parked on the Hornet deck that never move any parts, a hull baked into a static mesh would let all of them share one copy. The propellers are already separate components, so they can still spin. This saves the most, but loses bone animation and needs its own blueprint.
    
    **Also possible, but I'd only test it:** turning on Nanite for the skeletal mesh. It's one checkbox, but the hull has glass sections and I'm not sure how they behave under Nanite in 5.8. Each plane would also still have its own animated ray tracing copy.
    
    **Fix you can do today with no asset changes:** on the background planes in the level, hide the cockpit component or untick its *Visible in Ray Tracing*. Doing that on 15 planes removes about 11.4M skinned triangles straight away.
