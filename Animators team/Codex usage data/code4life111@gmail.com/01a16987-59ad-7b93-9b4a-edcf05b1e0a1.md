    | Action | Proposed behavior |
    |---|---|
    | **Get update** | Download, authenticate and stage the selected release while current work continues. |
    | **Update** | Stop accepting affected work, finish existing work, activate, restart and verify the target version. |
    | **Restart** | Restart the selected module or supervisor with the same drain rules. |
    | **Reconnect** | Re-establish communication while preserving job identities and journals. |
