# Anim Team Librarian

Anim Team Librarian backs up a team member’s saved Codex chats to their seat-email folder in [Usage data](../../../Usage%20data/Animators%20team/). The Windows task commits changed chats and optional session pictures together at 10:00 PM local time and checks for missed evenings.

## Current release

Download [Anim Team Librarian 0.5.0](releases/anim-team-librarian-0.5.0.zip) and follow the [installation and enrollment instructions](marketplace/plugins/anim-team-librarian/README.md). The [marketplace source](marketplace/) corresponds to this release.
