# Character Art Team Librarian

Character Art Team Librarian backs up a team member's saved Claude Code sessions to their seat-email folder in [Usage data](../../../Usage%20data/Character%20art%20team/). The Windows task commits changed sessions and optional session pictures together at 10:00 PM local time and checks for missed evenings.

## Current release

Download [Character Art Team Librarian 0.1.0](releases/character-art-team-librarian-0.1.0.zip) and follow the [installation and enrollment instructions](marketplace/plugins/character-art-team-librarian/README.md). The [marketplace source](marketplace/) corresponds to this release.
