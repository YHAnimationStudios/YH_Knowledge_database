# 3D Art Team Librarian

3D Art Team Librarian backs up a team member's saved Claude Code sessions to their seat-email folder in [Usage data](../../../Usage%20data/3D%20art%20team/). The Windows task commits changed sessions and optional session pictures together at 10:00 PM local time and checks for missed evenings.

## Install from GitHub

With Git on this PC signed in to GitHub (the repository is private), run:

```powershell
claude plugin marketplace add YHAnimationStudios/YH_Knowledge_database
claude plugin install 3d-art-team-librarian@yh-team-tools
```

Then follow the [enrollment instructions](marketplace/plugins/3d-art-team-librarian/README.md).

## Current release

Alternatively, download [3D Art Team Librarian 0.1.1](releases/3d-art-team-librarian-0.1.1.zip) and follow the [installation and enrollment instructions](marketplace/plugins/3d-art-team-librarian/README.md). The [marketplace source](marketplace/) corresponds to this release.
