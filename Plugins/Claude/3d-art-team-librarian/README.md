# 3D Art Team Librarian

3D Art Team Librarian backs up a team member's saved Claude Code sessions to their seat-email folder in [Usage data](../../../Usage%20data/). The Windows task commits changed sessions and optional session pictures together at 10:00 PM local time and checks for missed evenings.

## Current release

Download [3D Art Team Librarian 0.1.0](releases/3d-art-team-librarian-0.1.0.zip) and follow the [installation and enrollment instructions](marketplace/plugins/3d-art-team-librarian/README.md). The [marketplace source](marketplace/) corresponds to this release.
